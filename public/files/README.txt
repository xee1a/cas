Put DOCUMENTS here (PDFs used as CAS evidence).

How to use:
1. Copy the PDF into this folder (public/files/).
2. In the entry file (.md), add an attachment, e.g.:

   attachments:
     - src: /files/file-name.pdf
       label: "Name shown on the page"

Note: the path always starts with /files/... (no "public").

  plan-druk-3d.pdf   -> druk-3d-dla-dzieci.md (3D printing lesson plan)
